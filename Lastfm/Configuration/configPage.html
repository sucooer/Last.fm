Last.fm 授权（API Key + Token 流程）
  1. 用你的 Last.fm 账号在 https://www.last.fm/api/account/create 免费注册一个 API 应用（Callback URL 可留空），拿到 API Key 和 Shared Secret。
  2. 把 Key / Secret 填到下方，点「保存 API 配置」。
  3. 点「① 获取授权链接」，浏览器会跳转到 Last.fm 授权页，登录并点击「允许（Authorize）」。
  4. 回到本页点「② 完成授权」，看到“授权成功”即完成，之后播放音乐即自动 scrobble。
① 获取授权链接 ② 完成授权

说明：保存配置只保存 Key/Secret，不会显示已保存值；授权状态在「② 完成授权」的结果页里显示。 如果 Emby 重启过，授权 token 会失效，需要重新从①开始。
